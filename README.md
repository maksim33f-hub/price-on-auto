# Price on Auto — исследовательский анализ объявлений о продаже автомобилей

**Статус проекта:** в разработке  
**Тип проекта:** Pet-проект по анализу данных  
**Основной инструмент:** Python, Jupyter Notebook

## Описание проекта

Проект посвящён исследованию данных объявлений о продаже автомобилей. Основная задача — изучить распределение стоимости автомобилей и исследовать, как различные характеристики автомобиля связаны с его ценой.

В рамках проекта проводится предобработка данных, исследовательский анализ (EDA), расчёт статистических показателей и визуализация зависимостей между признаками.

В дальнейшем планируется эксперимент с моделями машинного обучения для восстановления пропущенных значений некоторых категориальных характеристик.

## Используемые технологии

- **Python** — основной язык программирования.
- **Pandas** — обработка и анализ табличных данных.
- **NumPy** — работа с массивами и числовыми данными.
- **Matplotlib** — построение графиков.
- **Seaborn** — статистическая визуализация.
- **SciPy** — расчёт статистических показателей.
- **Scikit-learn** — подготовка данных для экспериментов с машинным обучением.
- **Jupyter Notebook** — среда проведения исследования.

## Данные

Для анализа используется датасет **Craigslist Vehicles** с Kaggle (`vehicles.csv`), содержащий исходный объем **1.45 ГБ** и **26 колонок** (`id`, `url`, `region`, `region_url`, `price`, `year`, `manufacturer`, `model`, `condition`, `cylinders`, `fuel`, `odometer`, `title_status`, `transmission`, `VIN`, `drive`, `size`, `paint_color`, `image_url`, `description`, `country`, `state`, `lat`, `long`, `posting_date`).

Из-за большого объема данных и для оптимизации работы моделей на этапе предобработки были отобраны только самые ценные признаки. Технические идентификаторы, ссылки (`id`, `url`, `image_url`), а также избыточные или слабо влияющие на стоимость параметры были исключены.

В итоговый рабочий набор вошли следующие характеристики:

| Признак | Описание |
|---|---|
| `region` | Регион размещения объявления |
| `price` | Стоимость автомобиля |
| `year` | Год выпуска |
| `manufacturer` | Производитель |
| `condition` | Состояние автомобиля |
| `cylinders` | Количество цилиндров |
| `type` | Тип кузова |
| `fuel` | Тип топлива |
| `transmission` | Трансмиссия |
| `odometer` | Пробег автомобиля |

**Где взять данные:** Исходный файл слишком велик для хранения в репозитории. Вы можете скачать его напрямую с [Kaggle (Craigslist Vehicles Dataset)](https://www.kaggle.com/datasets/austinreese/craigslist-carstrucks-data/data) и разместить в корневой папке проекта перед запуском Jupyter Notebook.
## Выполненная работа

### 1. Первичный анализ данных

- Загрузка исходного набора данных.
- Изучение структуры таблицы и типов признаков.
- Проверка количества пропущенных значений.
- Анализ уникальных значений категориальных признаков.

### 2. Предобработка данных

- Обработка пропусков в категориальных признаках.
- Преобразование и проверка данных о годе выпуска.
- Фильтрация аномальных значений стоимости и пробега.
- Подготовка данных для последующего анализа.

В текущем варианте исследования используются ограничения:
- пробег — менее 350 000;
- стоимость — более 1 000 и менее 50 000.

### 3. Статистический анализ

Для изучения распределений и характеристик данных рассчитываются:
- среднее арифметическое;
- медиана;
- усечённое среднее.

Статистические показатели используются для анализа стоимости и пробега автомобилей, в том числе после фильтрации аномальных значений.

### 4. Исследовательский анализ данных (EDA)

Исследуются следующие взаимосвязи:

- стоимость автомобиля и производитель;
- стоимость автомобиля и количество цилиндров;
- стоимость автомобиля и пробег;
- распределение автомобилей по годам выпуска;
- стоимость автомобиля и тип кузова;
- стоимость автомобиля и состояние.

Для визуального анализа используются гистограммы, диаграммы рассеяния, столбчатые диаграммы и boxplot.

## Текущий этап разработки

На данный момент реализованы основные этапы предобработки данных и исследовательского анализа.

Также начата подготовка к экспериментам с машинным обучением. Рассматривается возможность предсказания пропущенных значений признаков `type` и `condition` на основе остальных характеристик автомобиля.

## Запуск проекта

1. Клонировать репозиторий:

   ```bash
   git clone <repository-url>
   ```

2. Перейти в папку проекта:

   ```bash
   cd price-on-auto
   ```

3. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Разместить файл `vehicles.csv` в соответствии с путём, указанным в Notebook.

5. Открыть Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

6. Открыть `Price_on_auto.ipynb` и выполнить ячейки последовательно.
